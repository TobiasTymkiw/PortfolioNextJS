## 🚀 Live Demo

You can check out the live version here: [Tobias Tymkiw Portfolio](https://portfolio-tobiastymkiw.vercel.app/)

## 🛠️ Tech Stack

This project is built with modern web technologies:

* **Framework**: [Next.js 14](https://nextjs.org/) (App Router)
* **Language**: [TypeScript](https://www.typescriptlang.org/)
* **Styling**: [SASS/SCSS](https://sass-lang.com/) (Modular Styles)
* **Analytics**: [Vercel Analytics](https://vercel.com/docs/concepts/analytics)
* **Forms**: [React Hook Form](https://react-hook-form.com/) & [EmailJS](https://www.emailjs.com/)
* **Animations/UI**: [Swiper](https://swiperjs.com/) & [React Scroll](https://www.npmjs.com/package/react-scroll)

## 📁 Project Structure

The project is organized efficiently to ensure scalability and maintainability:

* **portfolio/**: The main Next.js application directory.
* **portfolio/src/app**: Application routes and layout.
* **portfolio/src/Components**: Modular UI components (About, Contact, Experience, Skills, etc.).
* **portfolio/src/assets**: Static assets like images and videos.
* **portfolio/styles**: Global SCSS variables and mixins.

## ⚙️ How to Run Locally

To set up this project locally, follow these steps:

1. Clone the repository:

   ```bash
   git clone https://github.com/TobiasTymkiw/PortfolioNextJS.git
   ```

2. Navigate to the project directory:

   ```bash
   cd PortfolioNextJS/portfolio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Run the development server:

   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.
